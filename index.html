How I work

  1. Understand the data

    Read the source, structure, and data dictionary before calculating anything.

  2. Validate and clean

    Check missing values, duplicates, and formats, then reshape the data so it is ready for analysis.

  3. Explore and diagnose

    Move from basic summaries to the “why” questions: SQL for large data, Python for visuals.

  4. Report honestly

    Clear charts together with the limits of the data. Correlation is never presented as causation.
